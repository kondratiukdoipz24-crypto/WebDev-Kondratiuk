## Підсумок лабораторної роботи №6

**1. Що змінилося у виводі git status після git add?**

Після git add файли перейшли до списку Changes to be committed. Це означає, що вони підготовлені до збереження в commit.

**2. Що показує git diff?**

Команда git diff показує зміни, які були зроблені у файлах після останнього commit.

**3. Чим відрізняється git switch main від git merge?**

git switch main перемикає мене на гілку main, а git merge об'єднує зміни з іншої гілки в поточну.

**4. Чому виник конфлікт і як ти його розв'язала?**

Конфлікт виник тому, що в двох гілках я змінила один і той самий рядок по-різному. Я відкрила файл, залишила спільний варіант заголовка та видалила службові рядки Git.

**5. Скільки commit-ів у моїй історії?**

Кількість commit-ів можна перевірити командою git log --oneline. У моїй історії збережено декілька commit-ів із різними змінами проєкту.
